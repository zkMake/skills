# TanStack Router

Distilled from TkDodo's blog, the TanStack blog, and the current docs. Targets `@tanstack/react-router` v1 (and TanStack Start, which builds on it).

## Mental model

The router is a **typed graph**, not a string matcher. Every route registers its path, params, search schema, loader data, and context into one generated tree, and `Link`, `useNavigate`, `redirect`, `useSearch`, `useParams`, and `useLoaderData` all read their types back out of it. A wrong `to`, a missing param, or an unvalidated search key is a compile error, not a runtime 404.

Three things flow **down** the route tree, each with its own rules:

- **Context** — dependency injection. Built parent → child by `beforeLoad`; children see everything their ancestors added.
- **Loader data** — per-route, cached by the router's own SWR cache, keyed by params + `loaderDeps`.
- **Search params** — validated per route, inherited by links, and the correct home for state that should survive a reload or a shared URL.

A navigation is not one operation. Route matching, serial `beforeLoad`, parallel loaders, and the actual React commit are separate lifetimes: a superseded navigation loses the right to publish but its loader work keeps running and still lands in the cache, and preload work is shared with the navigation that follows it. Design loaders to be idempotent and cancellable rather than assuming one-navigation-one-run.

## Rules that apply to every task

1. **Never hand-edit `routeTree.gen.ts`.** It is generated by the bundler plugin (`@tanstack/router-plugin`). Add the plugin before the framework plugin, and enable `autoCodeSplitting: true`.
2. **Register the router type once**, or every hook degrades to `any`:
   ```ts
   declare module '@tanstack/react-router' {
     interface Register { router: typeof router }
   }
   ```
3. **Reach for route-scoped APIs.** Inside a route file use `Route.useParams()`, `Route.useSearch()`, `Route.useLoaderData()`, `Route.useRouteContext()`. Elsewhere use `getRouteApi('/posts/$postId')` or pass `{ from: '/posts/$postId' }`. `{ strict: false }` widens types and is a last resort.
4. **URL state is state.** Anything a user would expect to survive a refresh, a back button, or a pasted link — filters, pagination, sort, open tab, selected id — belongs in validated search params, not `useState`.
5. **Validate search params with a schema** (`validateSearch`), with defaults and fallbacks, so a hand-mangled URL degrades instead of crashing.
6. **Every search param a loader reads must go through `loaderDeps`** — and nothing else. Loader deps are the loader's cache key; returning the whole search object reloads the route on every unrelated param change.
7. **Put shared services in router context**, typed via `createRootRouteWithContext<{ queryClient: QueryClient }>()()`, rather than importing singletons into loaders.
8. **Guard with `beforeLoad` + `throw redirect(...)`** on a pathless `_authenticated` layout route, not with a `useEffect` in a component.
9. **Enable `defaultPreload: 'intent'`.** Hover/touch preloading is the single largest perceived-performance win, and it is one line.
10. **When TanStack Query owns the data, set `defaultPreloadStaleTime: 0`** so exactly one cache decides freshness — and derive the loader's query options from route context so loader and component can never drift.
